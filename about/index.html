시스템 통합

숭실대학교에서 Software Engineering을 전공했고, 현재 SSAFY Robotics Track에서 Computer Vision, ROS 2, robot control을 공부하고 있습니다.

카메라 입력, backend, ROS 2, 로봇 제어, 운영 화면을 하나의 시스템으로 설계하고 구현합니다.

THING에서는 손동작 21개 landmark를 7축 텐던 구동과 실험 기록으로 연결했고, AQIS에서는 검사 결과를 ROS 2, Dobot, 실시간 dashboard로 연결했습니다.

요즘 붙잡고 있는 질문

  • Retargeting

    21개 손 랜드마크를 7-DoF 텐던 핸드의 안전한 관절 명령으로 retargeting하려면 어떤 보정이 필요할까?

    THING의 제어 경로를 출발점으로 joint limit, 입력 평활화, 영점 보정이 실제 손 모양과 모터 동작에 미치는 영향을 정리하고 있습니다.

  • Sim-to-real

    시뮬레이션의 동작을 실제 로봇으로 옮길 때 sensor noise·latency·contact dynamics의 domain gap을 어떻게 줄일까?

    Isaac Sim과 Isaac Lab에서 통신 지연, 센서 오차, 접촉·마찰 차이를 실패 조건과 함께 비교하는 방법을 배우고 있습니다.

  • Edge inference

    Jetson·Raspberry Pi 같은 엣지 디바이스에서 AI 추론을 운영하려면 latency·memory budget·observability를 어떻게 함께 설계할까?

    Ollama와 llama.cpp에서 양자화, context 길이, 초당 토큰 수, RAM·VRAM 사용량을 비교하며 로그와 상태 확인까지 포함한 배포 기준을 정리하고 있습니다.
