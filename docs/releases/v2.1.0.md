# SeMinKong Portfolio v2.1.0

현재 공개된 웹과 정적 포트폴리오를 묶은 릴리스입니다. 거주지 `Suwon, Republic of Korea` 정정까지 포함합니다.

## 주요 변경

- Home에 드래그·던지기·충돌을 지원하는 Kinetic 오브제를 추가하고, 물리 보간·글자 충돌 영역·고정 광원을 다듬었습니다. 모션 축소와 WebGL 미지원 환경에서는 정적 화면을 유지합니다.
- 손글씨가 완성되기 전에 스크롤하거나 이동하면 일부 획이 남지 않던 문제를 수정했습니다.
- Work 전환과 프로젝트 소개, THING 시연, 웹 타이포그래피를 정리했습니다. Home 인사말은 프로젝트 버튼과 같은 서체를 쓰며 `즐겁습니다.`의 별도 강조를 제거했습니다.
- Resume에 세로형 `상장 보기` 모달을 추가했습니다. 전시용 이미지에서 다른 수상자와 일련번호를 가리고, 공세민과 허용된 발급자 정보는 유지했습니다. 원본 이력서 PDF/DOCX는 소유자가 승인한 공개본을 유지합니다.
- 20쪽 A4 가로 정적 포트폴리오를 추가하고 웹 다운로드와 연결했습니다. 자기소개, About, 여섯 프로젝트, 실제 화면과 시스템 구조도, 프로젝트별 수상을 포함합니다. 수상은 THING 1건과 Briefit 3건으로 구분했습니다.
- PDF 표지 사진을 중앙 정렬하고, 캡션·문단 배치와 제목을 다듬었습니다. 반복 머리말, Portfolio/날짜 푸터, 장식용 번호를 제거했습니다. 프로필 사진은 PDF에만 포함합니다.
- Home·About·Resume·PDF의 거주지를 Suwon으로 통일했습니다.
