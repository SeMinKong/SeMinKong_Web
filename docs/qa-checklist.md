# QA checklist

## Build

- [ ] `npm.cmd run build` 성공
- [ ] 의존성 또는 번들 오류 없음
- [ ] `dist/`를 직접 수정하지 않음

## Desktop — 1280px

- [ ] Hero 제목과 궤도 필드가 겹치지 않음
- [ ] Motion, Field, Depth 버튼 상태가 실제 동작과 일치
- [ ] 프로젝트 드래그와 관성 동작
- [ ] 카드 2.5D가 부드럽게 복귀
- [ ] 키네틱 티커가 끊기지 않음

## Tablet — 768px

- [ ] 내비게이션과 Hero가 겹치지 않음
- [ ] 프로젝트 카드가 탐색 가능
- [ ] 텍스트 줄바꿈과 여백이 자연스러움
- [ ] 가로 페이지 overflow 없음

## Mobile — 390px

- [ ] 가로 페이지 overflow 없음
- [ ] 터치 세로 스크롤이 방해받지 않음
- [ ] 프로젝트 가로 스크롤 가능
- [ ] CTA와 토글의 터치 영역이 충분함
- [ ] 데스크톱 전용 장식이 콘텐츠를 가리지 않음

## Accessibility

- [ ] Skip link 동작
- [ ] 키보드로 링크와 버튼에 접근 가능
- [ ] 포커스 표시가 보임
- [ ] `aria-pressed`와 버튼 라벨 일치
- [ ] reduced-motion에서 콘텐츠가 숨지 않음
- [ ] Motion 수동 override 동작

## Browser runtime

- [ ] 콘솔 error 0건
- [ ] 예상하지 못한 warning 검토
- [ ] 숨겨진 탭에서 연속 모션 정지
- [ ] 다시 보이는 탭에서 사용자 상태를 유지하며 재개
- [ ] 빠른 포인터 이동에도 애니메이션이 누적되지 않음

## Final report

- [ ] 변경 파일 목록
- [ ] 실행한 검증 명령
- [ ] 확인한 화면 크기
- [ ] 남은 위험과 미검증 항목
