Context

AQIS는 생산 라인의 제품을 카메라로 검사하고, 불량 판정이 나오면 컨베이어와 로봇을 제어하는 스마트 팩토리 시스템입니다.

검사 결과와 장비 상태는 웹 대시보드에서 실시간으로 확인할 수 있습니다.

My role

  • RealSense와 YOLOv5 검사 결과를 시스템 이벤트로 연결
  • ROS 2 bridge와 장비별 adapter 구현
  • FastAPI REST·WebSocket 서비스와 React 운영 화면 개발
  • 컨베이어 정지와 Dobot vacuum pick-and-place 흐름 통합

System flow

제품 검사

RealSense의 RGB·Depth 입력을 받아 YOLOv5가 제품 상태를 판정합니다.

장비 제어

불량 이벤트가 발생하면 컨베이어를 멈추고 Dobot 작업을 실행합니다.

운영 화면

검사 결과와 장비 상태를 WebSocket으로 전달해 대시보드에 반영합니다.

Outcome

RealSense 입력에서 불량을 감지하면 컨베이어를 멈추고 Dobot pick-and-place를 실행하며, 결과와 장비 상태를 대시보드에 표시하는 흐름을 완성했습니다.
