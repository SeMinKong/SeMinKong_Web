Conveyor / robot

위치 조건과 목표 자세

객체가 검출 위치에 도달하면 공정을 전환합니다. UR5는 저장된 목표로 MoveJ를 호출하고, 객체의 부모를 그리퍼·AGV로 변경해 적재를 표현합니다.

AGV / waypoints

장면 좌표를 경로로 사용

RoboDK의 nav1~nav6 프레임을 읽고 구간별 위치를 보간합니다. 경로와 몸체 방향을 맞추는 조정을 맡았습니다.

Implementation scope

공정 시뮬레이션의 범위

객체 이름과 위치로 검출을 판정하는 운동학적 공정 시뮬레이션입니다. 접촉력·마찰·파지 성공이나 자율주행 경로는 계산하지 않습니다.

03 / SLAM & robot monitoring

지도·위치·관절을
각자의 좌표계로 관제

TurtleBot의 지도·센서 시연은 RViz에서, 카메라와 위치·장비 상태는 RealOps에서 확인합니다. Dobot은 ROS 관절값을 URDF 모델에 반영해 현재 자세를 함께 보여줍니다.

본인 · SLAM·지정 목표점 주행 구성, ROS 상태 수집, RealOps·MJPEG·URDF 관제
팀 시연 · TurtleBot SLAM·RViz 및 실제 로봇 동작

Joint state → model pose

관절값으로 URDF 자세 갱신

URDF의 링크 계층과 원점·회전축을 읽고, ROS에서 받은 라디안 값을 관절에 적용합니다. mimic 관절의 배율과 offset도 반영합니다.

q_view = multiplier × q_ros + offset원점 자세 복원 → 관절축 기준 회전

관절 상태를 3D 모델에 표시하는 뷰어이며, 동역학과 충돌 계산은 포함하지 않습니다.
