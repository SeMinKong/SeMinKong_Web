THING

사람의 손동작을 인식해 안전한 로봇 명령으로 바꾸고, 실제 텐던 핸드의 움직임과 실험 기록까지 연결한 ROS 2 시스템입니다.

Context

THING은 카메라로 읽은 사람의 손 자세를 텐던 구동 로봇 핸드가 실시간으로 따라 하도록 만든 Human-Mimetic robotics 프로젝트입니다.

단순 모터 제어를 넘어 비전 입력, 분산 장치 통신, 안전 제어, 관제 화면, 실험 데이터 보존을 하나의 운영 흐름으로 구성했습니다.

Demonstrations / 04 scenes

손 모양을 따라 하고, 실제 물체를 잡습니다.

기술 구성보다 먼저 로봇 손이 실제로 무엇을 하는지 볼 수 있도록 공개 저장소의 원본 시연을 네 장면으로 골랐습니다.

Built prototype

공개 저장소의 제작 기록과 시험 사진을 통해 실제 텐던 라우팅, 손가락 구조, Jetson 기반 landmark 인식 환경을 확인할 수 있습니다.

System path

Perception

Jetson에서 MediaPipe Hands가 21개 landmark를 검출하고 손 자세를 추정합니다.

Retargeting

엄지 3축과 네 손가락 굽힘 4축을 하나의 7축 HandCommand로 변환합니다.

Safe actuation

Raspberry Pi 5의 명령 중재와 Command Guard, GPIO E-Stop을 거쳐 DYNAMIXEL XL330 7개를 구동합니다.

Observability

React 관제 화면은 WebSocket·MJPEG 상태를 보여주고, rosbag2 기록은 JSON·CSV와 SHA-256 검증을 거쳐 데이터 포털로 이어집니다.

System design

  • Jetson, Raspberry Pi 5, browser, AWS EC2 사이의 책임을 분리한 ROS 2 기반 구조
  • 명령 제한, 비상 정지, 네트워크 복구 뒤 자동 재동작을 막는 안전 경계
  • 실시간 상태와 카메라 피드를 함께 확인하는 React 관제 인터페이스
  • CAD·STL·URDF와 3D 프린팅 기구를 포함한 텐던 구동 하드웨어 구성

Evidence / Public

실제 시연과 제작 기록으로 확인할 수 있습니다.

손동작 모방, 캔과 유연 물체 파지, 장치별 통신, 데이터 기록 흐름을 공개 저장소에서 확인할 수 있습니다.
