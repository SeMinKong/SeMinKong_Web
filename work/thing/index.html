담당한 작업

Blender로 손 기구를 설계해 3D 프린팅하고 텐던 구동부를 조립했습니다. U2D2 기반 모터 7개 동기 제어와 ROS 브릿지·Cyclone DDS 통신 설정을 맡았고, 비전 인식과 명령 중재·관제 파트는 팀원들과 나눠 구현했습니다.

핸드 시제품

아크릴 마운트에 모터와 스풀을 고정하고 텐던을 연결했습니다. 당김 위치와 장력을 반복 조정해 굽힌 손가락이 자연스럽게 원위치로 복귀하도록 맞췄습니다.

손동작에서 모터까지

Perception

Jetson에서 MediaPipe Hands가 21개 landmark를 검출하고 손 자세를 추정합니다.

Retargeting

엄지 3축과 네 손가락 굽힘 4축을 하나의 7축 HandCommand로 변환합니다.

Safe actuation

Raspberry Pi 5의 명령 중재와 Command Guard, GPIO E-Stop을 거쳐 DYNAMIXEL XL330 7개를 구동합니다.

Observability

React 관제 화면은 WebSocket·MJPEG 상태를 보여주고, rosbag2 기록은 JSON·CSV와 SHA-256 검증을 거쳐 데이터 포털로 이어집니다.

장치 구성

  • Jetson, Raspberry Pi 5, browser, AWS EC2 사이의 책임을 분리한 ROS 2 기반 구조. ROS 2 내부 통신은 DDS, EC2 기록 업로드는 HTTPS 사용
  • 명령 제한과 비상 정지, 네트워크 복구 뒤 자동 재동작 방지
  • 실시간 상태와 카메라 피드를 함께 확인하는 React 관제 인터페이스
  • CAD·STL·URDF와 3D 프린팅 기구를 포함한 텐던 구동 하드웨어 구성
