Workflow

사용자가 프로젝트 아이디어를 입력하면 UI/UX, API, 데이터베이스, 시스템 구조, 테스트, 배포 영역을 각각 독립된 대화로 시작합니다.

각 영역은 별도 상태와 대화 이력을 유지하고, 답변이 충분해지면 최종 구현 문서에 합쳐집니다.

State Model

  • LangGraph로 설계 영역별 상태와 진행 단계를 분리
  • 최대 세 번의 질문으로 필요한 요구사항을 구체화
  • FastAPI WebSocket으로 질문과 완료 상태를 즉시 전달
  • 완성된 영역별 설계를 한 문서로 병합

Document Output

여섯 설계 대화가 각자 상태를 유지하면서 진행되고, 완료된 결과를 하나의 구현 문서로 합치는 흐름을 웹에서 끝까지 사용할 수 있게 구현했습니다.
