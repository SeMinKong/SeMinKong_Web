Gameplay

전통 알까기를 브라우저 기반 실시간 아레나 게임으로 만들었습니다. 자신의 돌을 드래그해 튕기고, 상대를 보드 밖으로 밀어내면 돌의 크기와 질량이 달라집니다.

Server physics

모든 플레이어가 같은 결과를 보도록 서버를 상태의 기준으로 두었습니다. 서버가 60 FPS로 위치와 속도를 계산하고 결과를 Socket.io로 전달합니다.

  • 질량과 속도에 따른 탄성 충돌과 impulse 계산
  • 마찰과 감속, 고속 충돌 시 위치 보정
  • 킬 수에 따른 반경과 질량 변화
  • 접속 인원에 맞춘 아레나 크기 조절

Custom Physics

Matter.js 같은 범용 엔진 대신 게임에 필요한 원형 충돌만 다루는 TypeScript 물리 모듈을 직접 작성했습니다. 계산 범위를 좁혀 서버 루프와 상태 동기화 흐름을 명확하게 유지했습니다.
