Brain Tumor MRI

뇌 MRI 한 장에서 종양 유형 분류와 영역 분할을 동시에 수행하는 YOLO11 데모입니다.

분류와 분할

분류 모델은 신경교종, 수막종, 뇌하수체 종양, 비종양 4개 클래스를 예측하고, 분할 모델은 같은 영상에서 종양 영역을 찾아냅니다.

마스크를 다각형 라벨로 변환

원본 마스크 이미지를 YOLO 분할 학습용 폴리곤 라벨로 바꾸는 전처리 스크립트를 작성했습니다. 5×5 커널로 closing·opening을 적용해 자잘한 노이즈를 정리한 뒤 외부 윤곽만 추출했고, 점이 3개 미만이거나 전체 면적의 0.1%보다 작은 영역은 걸러냈습니다.

남은 좌표는 이미지 크기로 정규화해 원본과 같은 이름의 txt 라벨로 저장했습니다.

  1. 이진화·형태 정리mask > 1
    closing → opening
  2. 외부 윤곽 추출RETR_EXTERNAL
    점 수·면적 필터
  3. 좌표 정규화x/W · y/H
    YOLO polygon label
mask_to_polygons · 라벨 변환 ↗

모델별 데이터와 가중치

분류는 클래스별 이미지 폴더를, 분할은 이미지와 폴리곤 라벨 쌍을 사용합니다. 각각 yolo11m-cls.pt와 yolo11m-seg.pt에서 시작해 학습 함수와 가중치 저장 경로를 분리했습니다.

Classification이미지 → 클래스train_classification()
Segmentation이미지 + polygon → 영역train_segmentation()

분류와 분할 결과를 한 화면에

같은 MRI 이미지를 분류 모델과 분할 모델에 각각 통과시킨 뒤, 분할 결과 이미지(plot()) 위에 Top-1 분류 클래스와 신뢰도를 OpenCV로 함께 그려 출력합니다.

분류가 비종양으로 나오더라도 분할 모델은 그대로 실행해, 두 모델의 결과가 어긋나는 경우도 화면에서 그대로 확인할 수 있게 두었습니다.

  1. 같은 MRI 입력분류 predict · 분할 predict
  2. 결과 읽기클래스·확률 · 분할 overlay
  3. 통합 출력overlay 위에 클래스 문구 표시

평가 자료와 한계

당시 실험에서는 분류 Top-1 99.4%, Mask mAP50 92.7%를 기록했습니다. 다만 test 세트를 검증에 함께 사용했고 환자 단위 데이터 분리나 가중치·로그 공개까지는 챙기지 못해, 엄밀한 벤치마크보다는 구현 검증용 데모로 보고 있습니다.

모폴로지 전처리 과정에서 작은 병변이나 내부 빈 공간이 지워질 수 있고 비종양 클래스에 다른 병변이 섞일 수 있어, 임상 목적이 아닌 연구·시연 용도로만 제작했습니다.
