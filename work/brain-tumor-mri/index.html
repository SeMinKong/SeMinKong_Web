종양의 종류와 위치를
함께 확인

YOLO11 분류 모델은 glioma, meningioma, pituitary, no_tumor 네 클래스를 다룹니다. 별도의 분할 모델은 종양 영역을 표시합니다. 데이터 전처리부터 두 모델의 학습 스크립트, 추론 결과를 확인하는 웹 데모까지 구현했습니다.

01 / Mask → polygon

픽셀 마스크를
YOLO 다각형 라벨로 변환

그레이스케일 마스크에서 값이 1보다 큰 픽셀을 전경으로 삼습니다. 5×5 커널로 closing 후 opening을 적용하고, 외부 윤곽을 추출합니다. 점이 세 개 미만이거나 전체 이미지 면적의 0.1%보다 작은 윤곽은 제외합니다.

남은 점의 x·y를 이미지의 폭·높이로 나눠 비율 좌표로 기록합니다. 클래스와 좌표들을 원본 이미지와 같은 이름의 txt 파일에 저장해 분할 학습에 사용합니다.

  1. 이진화·형태 정리mask > 1
    closing → opening
  2. 외부 윤곽 추출RETR_EXTERNAL
    점 수·면적 필터
  3. 좌표 정규화x/W · y/H
    YOLO polygon label
mask_to_polygons · 라벨 변환 ↗

02 / Separate models

분류와 분할에 맞는
데이터와 가중치 사용

분류는 클래스별 이미지 폴더를, 분할은 이미지와 다각형 라벨 쌍을 사용합니다. 각각 yolo11m-cls.pt와 yolo11m-seg.pt에서 시작하며, 학습 함수와 저장하는 가중치를 나누었습니다.

Classification이미지 → 클래스train_classification()
Segmentation이미지 + polygon → 영역train_segmentation()

03 / Integrated inference

같은 MRI에 두 모델을 호출하고
결과를 한 화면에 표시

통합 추론은 같은 MRI를 분류 모델과 분할 모델에 차례로 입력합니다. 분류의 top-1 클래스·확률을 읽고, 분할 결과의 plot() 이미지에 OpenCV로 문구를 더해 저장합니다.

분류가 비종양을 반환해도 분할은 실행합니다. 한 모델의 결과로 다른 모델을 건너뛰거나 두 예측의 불일치를 자동 수정하지 않습니다.

  1. 같은 MRI 입력분류 predict · 분할 predict
  2. 결과 읽기클래스·확률 · 분할 overlay
  3. 통합 출력overlay 위에 클래스 문구 표시
통합 추론 소스 ↗

평가 자료와 한계

저장소 README 보고치는 분류 Top-1 99.4%, Mask mAP50 92.7%입니다. 공개 가중치·학습 로그가 없어 독립 재현된 수치로 제시할 수는 없습니다. 학습 설정은 test 데이터를 validation에 사용하며 환자 단위 독립성도 확인되지 않았습니다.

마스크 정제는 작은 병변이나 내부 구멍을 지울 수 있습니다. 비종양 클래스에는 다른 병변이 포함될 수 있으며, 이 프로젝트는 연구·시연용입니다.
