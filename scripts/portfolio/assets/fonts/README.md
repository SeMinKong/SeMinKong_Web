# Portfolio PDF fonts

Unmodified NanumGothic fonts from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/nanumgothic), retrieved 2026-09-12. Copyright NHN Corporation; distributed under the accompanying SIL Open Font License 1.1 in `OFL.txt`.

These are the font edition used by the previously approved PDF. The builder checks their SHA-256 before registration so a different system-installed edition cannot silently change unchanged pages. They are build inputs only and are not copied to the website as standalone fonts.

| File | SHA-256 |
| --- | --- |
| NanumGothic-Regular.ttf | `76f45ef4a6bcff344c837c95a7dcc26e017e38b5846d5ae0cdcb5b86be2e2d31` |
| NanumGothic-Bold.ttf | `f96298f9fb18e364d2370f4c3ce948ac67a2b61af992d7234bc15c42b033c674` |

`PORTFOLIO_FONT_DIR` may provide another location for the same approved bytes; it does not bypass the version check.
